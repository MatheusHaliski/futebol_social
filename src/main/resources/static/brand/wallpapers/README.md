# Papéis de parede (Aparência → Tela de fundo)

Grade de ícones de futebol com holofote radial, em cinco paletas — equivalentes vetoriais das artes
enviadas pelo produto (verde, ciano, ouro, verde-claro, verde-vivo). Gerados por script (determinísticos), ~90 KB cada.

Para usar a arte original em bitmap, coloque o arquivo aqui como `custom-<nome>.jpg|png|webp` e selecione
"Personalizado" na Central de Privacidade → Aparência, ou envie pelo próprio app (upload em `/v1/media`).
